= SecurityMockMvcRequestBuilders

Spring MVC Test cũng cung cấp một interface `RequestBuilder` có thể được sử dụng để tạo `MockHttpServletRequest` dùng trong test của bạn.
Spring Security cung cấp một số implementation của `RequestBuilder` giúp việc testing dễ dàng hơn.
Để sử dụng các implementation `RequestBuilder` của Spring Security, hãy đảm bảo sử dụng static import sau:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
import static org.springframework.security.test.web.servlet.request.SecurityMockMvcRequestBuilders.*;
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
import org.springframework.security.test.web.servlet.request.SecurityMockMvcRequestBuilders.*
----
======
