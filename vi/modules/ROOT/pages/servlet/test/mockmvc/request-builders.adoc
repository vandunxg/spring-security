= SecurityMockMvcRequestBuilders

Spring MVC Test cũng cung cấp một interface `RequestBuilder` có thể được sử dụng để tạo `MockHttpServletRequest` dùng trong test.
Spring Security cung cấp một số implementation của `RequestBuilder` để việc testing trở nên dễ dàng hơn.
Để sử dụng các implementation của `RequestBuilder` do Spring Security cung cấp, hãy đảm bảo sử dụng static import sau:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
import static org.springframework.security.test.web.servlet.request.SecurityMockMvcRequestBuilders.*;
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
import org.springframework.security.test.web.servlet.request.SecurityMockMvcRequestBuilders.*
----
======
