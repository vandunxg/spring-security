= SecurityMockMvcResultMatchers

Đôi khi, cần thực hiện nhiều phép khẳng định liên quan đến bảo mật đối với một request.
Để đáp ứng nhu cầu này, tính năng hỗ trợ Spring Security Test triển khai interface `ResultMatcher` của Spring MVC Test.
Để sử dụng các triển khai `ResultMatcher` của Spring Security, hãy đảm bảo sử dụng static import sau:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
import static org.springframework.security.test.web.servlet.response.SecurityMockMvcResultMatchers.*;
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
import org.springframework.security.test.web.servlet.response.SecurityMockMvcResultMatchers.*

----
======

== Khẳng định chưa authentication

Đôi khi, việc khẳng định rằng không có người dùng đã được authentication nào gắn với kết quả của một lần gọi `MockMvc` là hữu ích.
Ví dụ, bạn có thể muốn kiểm thử việc gửi username và password không hợp lệ rồi xác minh rằng không có người dùng nào được authentication.
Bạn có thể dễ dàng thực hiện điều này với tính năng hỗ trợ kiểm thử của Spring Security bằng cách như sau:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
mvc
	.perform(formLogin().password("invalid"))
	.andExpect(unauthenticated());
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
mvc
    .perform(formLogin().password("invalid"))
    .andExpect { unauthenticated() }
----
======

== Khẳng định đã authentication

Thông thường, chúng ta cần khẳng định rằng có một người dùng đã được authentication.
Ví dụ, chúng ta có thể muốn xác minh rằng việc authentication đã thành công.
Chúng ta có thể xác minh rằng Form Login thành công bằng đoạn code sau:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
mvc
	.perform(formLogin())
	.andExpect(authenticated());
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
mvc
    .perform(formLogin())
    .andExpect { authenticated() }
----
======

Nếu muốn khẳng định các role của người dùng, chúng ta có thể tinh chỉnh code trước đó như sau:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
mvc
	.perform(formLogin().user("admin"))
	.andExpect(authenticated().withRoles("USER","ADMIN"));
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
mvc
    .perform(formLogin())
    .andExpect { authenticated().withRoles("USER","ADMIN") }
----
======

Ngoài ra, chúng ta có thể xác minh username:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
mvc
	.perform(formLogin().user("admin"))
	.andExpect(authenticated().withUsername("admin"));
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
mvc
    .perform(formLogin().user("admin"))
    .andExpect { authenticated().withUsername("admin") }
----
======

Chúng ta cũng có thể kết hợp các phép khẳng định:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
mvc
	.perform(formLogin().user("admin"))
	.andExpect(authenticated().withUsername("admin").withRoles("USER", "ADMIN"));
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
mvc
    .perform(formLogin().user("admin"))
    .andExpect { authenticated().withUsername("admin").withRoles("USER", "ADMIN") }
----
======

Chúng ta cũng có thể thực hiện các phép khẳng định tùy ý trên authentication

[tabs]
======
Java::
+
[source,java,role="primary"]
----
mvc
	.perform(formLogin())
	.andExpect(authenticated().withAuthentication(auth ->
		assertThat(auth).isInstanceOf(UsernamePasswordAuthenticationToken.class)));
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
mvc
    .perform(formLogin())
    .andExpect {
        authenticated().withAuthentication { auth ->
            assertThat(auth).isInstanceOf(UsernamePasswordAuthenticationToken::class.java) }
        }
    }
----
======
