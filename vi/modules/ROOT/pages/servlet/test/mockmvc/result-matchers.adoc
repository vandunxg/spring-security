= SecurityMockMvcResultMatchers

Đôi khi, cần thực hiện nhiều assertion liên quan đến security đối với một request.
Để đáp ứng nhu cầu này, testing support của Spring Security triển khai interface `ResultMatcher` của Spring MVC Test.
Để sử dụng các implementation `ResultMatcher` của Spring Security, hãy đảm bảo sử dụng static import sau:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
import static org.springframework.security.test.web.servlet.response.SecurityMockMvcResultMatchers.*;
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
import org.springframework.security.test.web.servlet.response.SecurityMockMvcResultMatchers.*

----
======

== Assertion về trạng thái unauthenticated

Đôi khi, việc assert rằng không có authenticated user nào gắn với kết quả của một lần gọi `MockMvc` có thể hữu ích.
Ví dụ, bạn có thể muốn kiểm thử việc gửi username và password không hợp lệ rồi verify rằng không có user nào được authenticated.
Bạn có thể dễ dàng thực hiện điều này với testing support của Spring Security như sau:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
mvc
	.perform(formLogin().password("invalid"))
	.andExpect(unauthenticated());
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
mvc
    .perform(formLogin().password("invalid"))
    .andExpect { unauthenticated() }
----
======

== Assertion về trạng thái authenticated

Thông thường, chúng ta cần assert rằng có một authenticated user.
Ví dụ, chúng ta có thể muốn verify rằng authentication đã thành công.
Chúng ta có thể verify rằng form-based login đã thành công bằng đoạn code sau:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
mvc
	.perform(formLogin())
	.andExpect(authenticated());
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
mvc
    .perform(formLogin())
    .andExpect { authenticated() }
----
======

Nếu muốn assert các role của user, chúng ta có thể tinh chỉnh đoạn code trước như sau:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
mvc
	.perform(formLogin().user("admin"))
	.andExpect(authenticated().withRoles("USER","ADMIN"));
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
mvc
    .perform(formLogin())
    .andExpect { authenticated().withRoles("USER","ADMIN") }
----
======

Ngoài ra, chúng ta có thể verify username:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
mvc
	.perform(formLogin().user("admin"))
	.andExpect(authenticated().withUsername("admin"));
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
mvc
    .perform(formLogin().user("admin"))
    .andExpect { authenticated().withUsername("admin") }
----
======

Chúng ta cũng có thể kết hợp các assertion:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
mvc
	.perform(formLogin().user("admin"))
	.andExpect(authenticated().withUsername("admin").withRoles("USER", "ADMIN"));
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
mvc
    .perform(formLogin().user("admin"))
    .andExpect { authenticated().withUsername("admin").withRoles("USER", "ADMIN") }
----
======

Chúng ta cũng có thể thực hiện các assertion tùy ý trên authentication

[tabs]
======
Java::
+
[source,java,role="primary"]
----
mvc
	.perform(formLogin())
	.andExpect(authenticated().withAuthentication(auth ->
		assertThat(auth).isInstanceOf(UsernamePasswordAuthenticationToken.class)));
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
mvc
    .perform(formLogin())
    .andExpect {
        authenticated().withAuthentication { auth ->
            assertThat(auth).isInstanceOf(UsernamePasswordAuthenticationToken::class.java) }
        }
    }
----
======
