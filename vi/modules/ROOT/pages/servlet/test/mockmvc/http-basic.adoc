= Kiểm thử HTTP Basic Authentication

Mặc dù việc thực hiện authentication bằng HTTP Basic luôn khả thi, việc ghi nhớ tên header, định dạng và mã hóa các giá trị hơi tẻ nhạt.
Giờ đây, bạn có thể thực hiện việc này bằng `httpBasic` xref:servlet/test/mockmvc/request-post-processors.adoc[`RequestPostProcessor`] của Spring Security.
Ví dụ, đoạn mã dưới đây:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
mvc
	.perform(get("/").with(httpBasic("user","password")))
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
mvc.get("/") {
    with(httpBasic("user","password"))
}
----
======

sẽ cố gắng sử dụng HTTP Basic để thực hiện authentication cho người dùng có username là "user" và password là "password" bằng cách bảo đảm header sau được điền trong HTTP Request:

[source,text]
----
Authorization: Basic dXNlcjpwYXNzd29yZA==
----
