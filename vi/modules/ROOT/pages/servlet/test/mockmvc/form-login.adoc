= Kiểm thử Form-based Authentication

Bạn có thể dễ dàng tạo một request để kiểm thử form-based authentication bằng testing support của Spring Security.
Ví dụ, `formLogin` xref:servlet/test/mockmvc/request-post-processors.adoc[`RequestPostProcessor`] sau sẽ gửi một POST request đến "/login" với username "user", password "password" và một CSRF token hợp lệ:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
mvc
	.perform(formLogin())
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
mvc
	.perform(formLogin())
----
======

Bạn có thể dễ dàng tùy chỉnh request.
Ví dụ, đoạn sau sẽ gửi một POST request đến "/auth" với username "admin", password "pass" và một CSRF token hợp lệ:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
mvc
	.perform(formLogin("/auth").user("admin").password("pass"))
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
mvc
    .perform(formLogin("/auth").user("admin").password("pass"))
----
======

Bạn cũng có thể tùy chỉnh tên của các parameter chứa username và password.
Ví dụ, request ở trên được sửa đổi để đưa username vào HTTP parameter "u" và password vào HTTP parameter "p".

[tabs]
======
Java::
+
[source,java,role="primary"]
----
mvc
	.perform(formLogin("/auth").user("u","admin").password("p","pass"))
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
mvc
    .perform(formLogin("/auth").user("u","admin").password("p","pass"))
----
======
