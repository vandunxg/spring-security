[[test-mockmvc-setup]]
= Thiết lập MockMvc và Spring Security

[NOTE]
====
Hỗ trợ kiểm thử của Spring Security yêu cầu spring-test-4.1.3.RELEASE trở lên.
====

Để sử dụng Spring Security với Spring MVC Test, thêm `FilterChainProxy` của Spring Security dưới dạng một `Filter`.
Bạn cũng cần thêm `TestSecurityContextHolderPostProcessor` của Spring Security để hỗ trợ xref:servlet/test/mockmvc/authentication.adoc#test-mockmvc-withmockuser[Chạy với tư cách người dùng trong Spring MVC Test bằng annotation].
Để thực hiện việc đó, sử dụng `SecurityMockMvcConfigurers.springSecurity()` của Spring Security:

[tabs]
======
Java::
+
[source,java,role="primary"]
----

import static org.springframework.security.test.web.servlet.setup.SecurityMockMvcConfigurers.*;

@ExtendWith(SpringExtension.class)
@ContextConfiguration(classes = SecurityConfig.class)
@WebAppConfiguration
public class CsrfShowcaseTests {

	@Autowired
	private WebApplicationContext context;

	private MockMvc mvc;

	@BeforeEach
	public void setup() {
		mvc = MockMvcBuilders
				.webAppContextSetup(context)
				.apply(springSecurity()) // <1>
				.build();
	}
	// ...
}
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
@ExtendWith(SpringExtension::class)
@ContextConfiguration(classes = [SecurityConfig::class])
@WebAppConfiguration
class CsrfShowcaseTests {

    @Autowired
    private lateinit var context: WebApplicationContext

    private lateinit var mvc: MockMvc

    @BeforeEach
    fun setup() {
        mvc = MockMvcBuilders
            .webAppContextSetup(context)
            .apply<DefaultMockMvcBuilder>(springSecurity()) // <1>
            .build()
    }
    // ...
}
----
======
<1> `SecurityMockMvcConfigurers.springSecurity()` sẽ thực hiện toàn bộ thiết lập ban đầu cần thiết để tích hợp Spring Security với Spring MVC Test

Sau khi đã cấu hình MockMvc với `springSecurity()`, bạn có thể sử dụng các xref:servlet/test/mockmvc/request-post-processors.adoc[RequestPostProcessors] của Security và các hỗ trợ kiểm thử MockMvc khác.
