[[test-mockmvc-csrf]]
= Kiểm thử với cơ chế bảo vệ CSRF

Khi kiểm thử bất kỳ phương thức HTTP không an toàn nào và sử dụng cơ chế bảo vệ CSRF của Spring Security, bạn phải đưa một CSRF Token hợp lệ vào request.
Để chỉ định một CSRF token hợp lệ dưới dạng request parameter, hãy sử dụng CSRF xref:servlet/test/mockmvc/request-post-processors.adoc[`RequestPostProcessor`] như sau:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
mvc
	.perform(post("/").with(csrf()))
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
mvc.post("/") {
    with(csrf())
}
----
======

Nếu muốn, thay vào đó bạn có thể đưa CSRF token vào header:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
mvc
	.perform(post("/").with(csrf().asHeader()))
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
mvc.post("/") {
    with(csrf().asHeader())
}
----
======

Bạn cũng có thể kiểm thử việc cung cấp một CSRF token không hợp lệ bằng cách sử dụng đoạn sau:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
mvc
	.perform(post("/").with(csrf().useInvalidToken()))
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
mvc.post("/") {
    with(csrf().useInvalidToken())
}
----
======
