[[test-mockmvc-csrf]]
= Kiểm thử với cơ chế bảo vệ CSRF

Khi kiểm thử bất kỳ HTTP method không an toàn nào và sử dụng cơ chế bảo vệ CSRF của Spring Security, bạn phải đưa CSRF token hợp lệ vào request.
Để chỉ định CSRF token hợp lệ dưới dạng request parameter, hãy sử dụng xref:servlet/test/mockmvc/request-post-processors.adoc[`RequestPostProcessor`] dành cho CSRF như sau:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
mvc
	.perform(post("/").with(csrf()))
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
mvc.post("/") {
    with(csrf())
}
----
======

Nếu muốn, thay vào đó bạn có thể đưa CSRF token vào header:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
mvc
	.perform(post("/").with(csrf().asHeader()))
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
mvc.post("/") {
    with(csrf().asHeader())
}
----
======

Bạn cũng có thể kiểm thử với CSRF token không hợp lệ như sau:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
mvc
	.perform(post("/").with(csrf().useInvalidToken()))
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
mvc.post("/") {
    with(csrf().useInvalidToken())
}
----
======
