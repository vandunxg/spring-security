= SecurityMockMvcRequestPostProcessors
:page-section-summary-toc: 1
Spring MVC Test cung cấp một interface thuận tiện (`RequestPostProcessor`) mà bạn có thể sử dụng để sửa đổi request.
Spring Security cung cấp một số implementation của `RequestPostProcessor` giúp việc testing dễ dàng hơn.
Để sử dụng các implementation của `RequestPostProcessor` trong Spring Security, hãy sử dụng static import sau:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
import static org.springframework.security.test.web.servlet.request.SecurityMockMvcRequestPostProcessors.*;
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
import org.springframework.security.test.web.servlet.request.SecurityMockMvcRequestPostProcessors.*
----
======
