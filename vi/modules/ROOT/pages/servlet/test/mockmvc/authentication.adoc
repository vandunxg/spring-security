[[test-mockmvc-securitycontextholder]]
= Chạy một bài kiểm thử với tư cách người dùng trong Spring MVC Test

Thông thường, bạn muốn chạy các bài kiểm thử với tư cách một người dùng cụ thể.
Có hai cách đơn giản để thiết lập người dùng:

* <<test-mockmvc-securitycontextholder-rpp,Chạy với tư cách người dùng trong Spring MVC Test bằng RequestPostProcessor>>
* <<test-mockmvc-withmockuser,Chạy với tư cách người dùng trong Spring MVC Test bằng annotation>>

[[test-mockmvc-securitycontextholder-rpp]]
== Chạy với tư cách người dùng trong Spring MVC Test bằng RequestPostProcessor

Bạn có một số lựa chọn để liên kết người dùng với `HttpServletRequest` hiện tại.
Ví dụ sau chạy với tư cách một người dùng (không cần tồn tại) có tên người dùng là `user`, mật khẩu là `password` và role là `ROLE_USER`:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
mvc
	.perform(get("/").with(user("user")))
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
mvc.get("/") {
    with(user("user"))
}
----
======

[NOTE]
====
Tính năng hỗ trợ này hoạt động bằng cách liên kết người dùng với `HttpServletRequest`.
Để liên kết request với `SecurityContextHolder`, bạn cần đảm bảo rằng `SecurityContextPersistenceFilter` được liên kết với đối tượng `MockMvc`.
Bạn có thể thực hiện việc này bằng một trong các cách sau:

* Gọi xref:servlet/test/mockmvc/setup.adoc#test-mockmvc-setup[`apply(springSecurity())`]
* Thêm `FilterChainProxy` của Spring Security vào `MockMvc`
* Khi sử dụng `MockMvcBuilders.standaloneSetup`, việc thêm thủ công `SecurityContextPersistenceFilter` vào đối tượng `MockMvc` có thể phù hợp
====



Bạn có thể dễ dàng thực hiện các tùy chỉnh.
Ví dụ, đoạn sau sẽ chạy với tư cách một người dùng (không cần tồn tại) có tên người dùng là "admin", mật khẩu là "pass" và các role là "ROLE_USER" và "ROLE_ADMIN".

[tabs]
======
Java::
+
[source,java,role="primary"]
----
mvc
	.perform(get("/admin").with(user("admin").password("pass").roles("USER","ADMIN")))
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
mvc.get("/admin") {
    with(user("admin").password("pass").roles("USER","ADMIN"))
}
----
======

Nếu bạn có một `UserDetails` tùy chỉnh muốn sử dụng, bạn cũng có thể dễ dàng chỉ định nó.
Ví dụ, đoạn sau sẽ sử dụng `UserDetails` được chỉ định (không cần tồn tại) để chạy với một `UsernamePasswordAuthenticationToken` có principal là `UserDetails` được chỉ định:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
mvc
	.perform(get("/").with(user(userDetails)))
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
mvc.get("/") {
    with(user(userDetails))
}
----
======

Bạn có thể chạy với tư cách người dùng ẩn danh bằng đoạn sau:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
mvc
	.perform(get("/").with(anonymous()))
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
mvc.get("/") {
    with(anonymous())
}
----
======

Điều này đặc biệt hữu ích khi bạn đang chạy với một người dùng mặc định và muốn xử lý một vài request với tư cách người dùng ẩn danh.

Nếu muốn sử dụng một `Authentication` tùy chỉnh (không cần tồn tại), bạn có thể thực hiện như sau:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
mvc
	.perform(get("/").with(authentication(authentication)))
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
mvc.get("/") {
    with(authentication(authentication))
}
----
======

Bạn thậm chí có thể tùy chỉnh `SecurityContext` bằng đoạn sau:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
mvc
	.perform(get("/").with(securityContext(securityContext)))
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
mvc.get("/") {
    with(securityContext(securityContext))
}
----
======

Bạn cũng có thể đảm bảo chạy với tư cách một người dùng cụ thể cho mọi request bằng request mặc định của ``MockMvcBuilders``.
Ví dụ, đoạn sau sẽ chạy với tư cách một người dùng (không cần tồn tại) có tên người dùng là "admin", mật khẩu là "password" và role là "ROLE_ADMIN":

[tabs]
======
Java::
+
[source,java,role="primary"]
----
mvc = MockMvcBuilders
		.webAppContextSetup(context)
		.defaultRequest(get("/").with(user("user").roles("ADMIN")))
		.apply(springSecurity())
		.build();
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
mvc = MockMvcBuilders
    .webAppContextSetup(context)
    .defaultRequest<DefaultMockMvcBuilder>(get("/").with(user("user").roles("ADMIN")))
    .apply<DefaultMockMvcBuilder>(springSecurity())
    .build()
----
======

Nếu nhận thấy mình đang sử dụng cùng một người dùng trong nhiều bài kiểm thử, bạn nên chuyển người dùng đó vào một method.
Ví dụ, bạn có thể chỉ định đoạn sau trong class có tên `CustomSecurityMockMvcRequestPostProcessors` của riêng mình:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
public static RequestPostProcessor rob() {
	return user("rob").roles("ADMIN");
}
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
fun rob(): RequestPostProcessor {
    return user("rob").roles("ADMIN")
}
----
======

Bây giờ bạn có thể thực hiện static import đối với `CustomSecurityMockMvcRequestPostProcessors` và sử dụng nó trong các bài kiểm thử:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
import static sample.CustomSecurityMockMvcRequestPostProcessors.*;

...

mvc
	.perform(get("/").with(rob()))
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
import sample.CustomSecurityMockMvcRequestPostProcessors.*

//...

mvc.get("/") {
    with(rob())
}
----
======

[[test-mockmvc-withmockuser]]
== Chạy với tư cách người dùng trong Spring MVC Test bằng annotation

Thay vì sử dụng một `RequestPostProcessor` để tạo người dùng, bạn có thể sử dụng các annotation được mô tả trong xref:servlet/test/method.adoc[Kiểm thử method security].
Ví dụ, đoạn sau sẽ chạy bài kiểm thử với người dùng có tên người dùng là "user", mật khẩu là "password" và role là "ROLE_USER":

[tabs]
======
Java::
+
[source,java,role="primary"]
----
@Test
@WithMockUser
public void requestProtectedUrlWithUser() throws Exception {
mvc
		.perform(get("/"))
		...
}
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
@Test
@WithMockUser
fun requestProtectedUrlWithUser() {
    mvc
        .get("/")
        // ...
}
----
======

Ngoài ra, đoạn sau sẽ chạy bài kiểm thử với người dùng có tên người dùng là "user", mật khẩu là "password" và role là "ROLE_ADMIN":

[tabs]
======
Java::
+
[source,java,role="primary"]
----
@Test
@WithMockUser(roles="ADMIN")
public void requestProtectedUrlWithUser() throws Exception {
mvc
		.perform(get("/"))
		...
}
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
@Test
@WithMockUser(roles = ["ADMIN"])
fun requestProtectedUrlWithUser() {
    mvc
        .get("/")
        // ...
}
----
======
