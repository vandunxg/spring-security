= SecurityMockMvcResultHandlers

Spring Security cung cấp một số implementation của ``ResultHandler``.
Để sử dụng các implementation của ``ResultHandler`` trong Spring Security, hãy đảm bảo sử dụng static import sau:

[source,java]
----
import static org.springframework.security.test.web.servlet.response.SecurityMockMvcResultHandlers.*;
----

== Xuất SecurityContext

Thông thường, chúng ta muốn truy vấn một repository để xem một request `MockMvc` có thực sự được lưu vào cơ sở dữ liệu hay không.
Trong một số trường hợp, truy vấn repository của chúng ta sử dụng xref:features/integrations/data.adoc[Tích hợp Spring Data] để lọc kết quả dựa trên username của người dùng hiện tại hoặc bất kỳ thuộc tính nào khác.
Hãy xem một ví dụ:

Một interface repository:
[source,java]
----
private interface MessageRepository extends JpaRepository<Message, Long> {
	@Query("SELECT m.content FROM Message m WHERE m.sentBy = ?#{ principal?.name }")
	List<String> findAllUserMessages();
}
----

Kịch bản test của chúng ta:

[source,java]
----
mvc
	.perform(post("/message")
		.content("New Message")
		.contentType(MediaType.TEXT_PLAIN)
	)
	.andExpect(status().isOk());

List<String> userMessages = messageRepository.findAllUserMessages();
assertThat(userMessages).hasSize(1);
----

Bài test này sẽ không thành công vì sau khi request của chúng ta hoàn tất, `SecurityContextHolder` sẽ bị filter chain clear.
Sau đó, chúng ta có thể export `TestSecurityContextHolder` sang `SecurityContextHolder` và sử dụng nó theo nhu cầu:

[source,java]
----
mvc
	.perform(post("/message")
		.content("New Message")
		.contentType(MediaType.TEXT_PLAIN)
	)
	.andDo(exportTestSecurityContext())
	.andExpect(status().isOk());

List<String> userMessages = messageRepository.findAllUserMessages();
assertThat(userMessages).hasSize(1);
----

[NOTE]
====
Hãy nhớ clear `SecurityContextHolder` giữa các test, nếu không context có thể bị rò rỉ từ test này sang test khác
====
