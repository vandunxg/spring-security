[[test-logout]]
= Kiểm thử logout

Mặc dù việc này khá đơn giản khi sử dụng Spring MVC Test tiêu chuẩn, bạn có thể sử dụng hỗ trợ kiểm thử của Spring Security để việc kiểm thử logout dễ dàng hơn.
Ví dụ, `logout` xref:servlet/test/mockmvc/request-post-processors.adoc[`RequestPostProcessor`] sau sẽ gửi một POST đến "/logout" kèm token CSRF hợp lệ:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
mvc
	.perform(logout())
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
mvc
    .perform(logout())
----
======

Bạn cũng có thể tùy chỉnh URL đích của POST.
Ví dụ, đoạn mã dưới đây sẽ gửi một POST đến "/signout" kèm token CSRF hợp lệ:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
mvc
	.perform(logout("/signout"))
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
mvc
	.perform(logout("/signout"))
----
======
