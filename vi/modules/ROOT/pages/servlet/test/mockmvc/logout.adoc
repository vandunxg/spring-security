[[test-logout]]
= Kiểm thử logout

Dù việc kiểm thử logout bằng Spring MVC Test tiêu chuẩn khá đơn giản, bạn có thể sử dụng testing support của Spring Security để việc kiểm thử logout trở nên dễ dàng hơn.
Ví dụ, `logout` xref:servlet/test/mockmvc/request-post-processors.adoc[`RequestPostProcessor`] sau sẽ gửi một POST request đến "/logout" kèm token CSRF hợp lệ:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
mvc
	.perform(logout())
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
mvc
    .perform(logout())
----
======

Bạn cũng có thể tùy chỉnh URL mà POST request sẽ gửi đến.
Ví dụ, đoạn code dưới đây sẽ gửi một POST request đến "/signout" kèm token CSRF hợp lệ:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
mvc
	.perform(logout("/signout"))
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
mvc
	.perform(logout("/signout"))
----
======
