[[cors]]
= CORS

Spring Framework cung cấp {spring-framework-reference-url}web/webmvc-cors.html[hỗ trợ hạng nhất cho CORS].
CORS phải được xử lý trước Spring Security, vì pre-flight request không chứa cookie nào (cụ thể là `JSESSIONID`).
Nếu request không chứa cookie nào và Spring Security được xử lý trước, Spring Security sẽ xác định rằng người dùng chưa được authenticated (vì request không có cookie nào) và từ chối request đó.

[[cors-configuration-source]]
== Cung cấp một `CorsConfigurationSource`

Cách dễ nhất để đảm bảo CORS được xử lý trước là sử dụng `CorsFilter`.
Bạn có thể tích hợp `CorsFilter` với Spring Security bằng cách cung cấp một `CorsConfigurationSource`.
Lưu ý rằng Spring Security sẽ tự động cấu hình CORS chỉ khi có một instance `UrlBasedCorsConfigurationSource`.
Ví dụ sau tích hợp hỗ trợ CORS trong Spring Security:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
@Bean
UrlBasedCorsConfigurationSource corsConfigurationSource() {
    CorsConfiguration configuration = new CorsConfiguration();
    configuration.setAllowedOrigins(Arrays.asList("https://example.com"));
    configuration.setAllowedMethods(Arrays.asList("GET","POST"));
    UrlBasedCorsConfigurationSource source = new UrlBasedCorsConfigurationSource();
    source.registerCorsConfiguration("/**", configuration);
    return source;
}
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
@Bean
fun corsConfigurationSource(): UrlBasedCorsConfigurationSource {
    val configuration = CorsConfiguration()
    configuration.allowedOrigins = listOf("https://example.com")
    configuration.allowedMethods = listOf("GET", "POST")
    val source = UrlBasedCorsConfigurationSource()
    source.registerCorsConfiguration("/**", configuration)
    return source
}
----
======

Đoạn mã sau thực hiện điều tương tự bằng XML:

[source,xml]
----
<http>
	<cors configuration-source-ref="corsSource"/>
	...
</http>
<b:bean id="corsSource" class="org.springframework.web.cors.UrlBasedCorsConfigurationSource">
	...
</b:bean>
----

[[cors-spring-mvc-integration]]
== Tích hợp Spring MVC

Nếu sử dụng hỗ trợ CORS của Spring MVC, bạn có thể bỏ qua việc chỉ định `CorsConfigurationSource` và Spring Security sẽ sử dụng cấu hình CORS được cung cấp cho Spring MVC:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
@Configuration
@EnableWebSecurity
public class WebSecurityConfig {

	@Bean
	public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
		http
			// if Spring MVC is on classpath and no CorsConfigurationSource is provided,
			// Spring Security will use CORS configuration provided to Spring MVC
			.cors(withDefaults())
			...
		return http.build();
	}
}
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
@Configuration
@EnableWebSecurity
open class WebSecurityConfig {
    @Bean
    open fun filterChain(http: HttpSecurity): SecurityFilterChain {
        http {
            // if Spring MVC is on classpath and no CorsConfigurationSource is provided,
            // Spring Security will use CORS configuration provided to Spring MVC
            cors { }
            // ...
        }
        return http.build()
    }
}
----
======

Đoạn mã sau thực hiện điều tương tự bằng XML:

[source,xml]
----
<http>
	<!-- Default to Spring MVC's CORS configuration -->
	<cors />
	...
</http>
----

[[cors-per-chain-configuration]]
== Cấu hình theo từng chain

Nếu có từ hai bean `CorsConfigurationSource` trở lên, Spring Security sẽ không tự động cấu hình hỗ trợ CORS cho bạn, vì nó không thể quyết định nên sử dụng bean nào.
Nếu muốn chỉ định một `CorsConfigurationSource` khác cho mỗi `SecurityFilterChain`, bạn có thể truyền trực tiếp `CorsConfigurationSource` đó vào DSL `.cors()`.

[tabs]
======
Java::
+
[source,java,role="primary"]
----
@Configuration
@EnableWebSecurity
public class WebSecurityConfig {

	@Bean
	@Order(0)
	public SecurityFilterChain apiFilterChain(HttpSecurity http) throws Exception {
		http
			.securityMatcher("/api/**")
			.cors((cors) -> cors
				.configurationSource(apiConfigurationSource())
			)
			...
		return http.build();
	}

	@Bean
	@Order(1)
	public SecurityFilterChain myOtherFilterChain(HttpSecurity http) throws Exception {
		http
			.cors((cors) -> cors
				.configurationSource(myWebsiteConfigurationSource())
			)
			...
		return http.build();
	}

	UrlBasedCorsConfigurationSource apiConfigurationSource() {
		CorsConfiguration configuration = new CorsConfiguration();
		configuration.setAllowedOrigins(Arrays.asList("https://api.example.com"));
		configuration.setAllowedMethods(Arrays.asList("GET","POST"));
		UrlBasedCorsConfigurationSource source = new UrlBasedCorsConfigurationSource();
		source.registerCorsConfiguration("/**", configuration);
		return source;
	}

	UrlBasedCorsConfigurationSource myWebsiteConfigurationSource() {
		CorsConfiguration configuration = new CorsConfiguration();
		configuration.setAllowedOrigins(Arrays.asList("https://example.com"));
		configuration.setAllowedMethods(Arrays.asList("GET","POST"));
		UrlBasedCorsConfigurationSource source = new UrlBasedCorsConfigurationSource();
		source.registerCorsConfiguration("/**", configuration);
		return source;
	}

}
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
@Bean
fun corsConfigurationSource(): UrlBasedCorsConfigurationSource {
    val configuration = CorsConfiguration()
    configuration.allowedOrigins = listOf("https://example.com")
    configuration.allowedMethods = listOf("GET", "POST")
    val source = UrlBasedCorsConfigurationSource()
    source.registerCorsConfiguration("/**", configuration)
    return source
}
----
======

[[cors-preflight-request-handler]]
== `PreFlightRequestHandler` và `PreFlightRequestFilter`

Spring Framework định nghĩa {spring-framework-api-url}org/springframework/web/cors/PreFlightRequestHandler.html[`PreFlightRequestHandler`] cho các ứng dụng cần xử lý các CORS preflight request (`OPTIONS`) bên ngoài `CorsFilter`.
Khi Spring Security chọn một `PreFlightRequestHandler` cho một filter chain, nó đăng ký {spring-framework-api-url}org/springframework/web/filter/PreFlightRequestFilter.html[`PreFlightRequestFilter`] trong security filter chain (trước `CorsFilter`) để preflight có thể được xử lý sớm trong vòng đời của request.

Bạn có thể cung cấp handler theo một trong các cách sau:

* Truyền trực tiếp một handler bằng attribute `preFlightRequestHandler`.
* Đăng ký một bean `PreFlightRequestHandler` khi CORS được bật và khi không có `CorsConfigurationSource` hoặc `CorsFilter` nào được chọn cho chain đó.

Bạn không được cấu hình đồng thời `configurationSource` và `preFlightRequestHandler` trên cùng một `CorsConfigurer`; nếu làm vậy, ứng dụng sẽ gặp lỗi khi khởi động.

Ví dụ sau đăng ký rõ ràng một `PreFlightRequestHandler` bằng `preFlightRequestHandler`:

include-code::./CorsPreFlightRequestHandlerExample[tag=preflightRequestHandler,indent=0]

[WARNING]
====
CORS là một tính năng bảo mật dựa trên trình duyệt.
Việc vô hiệu hóa CORS trong Spring Security bằng `.cors(CorsConfigurer::disable)` không loại bỏ cơ chế bảo vệ CORS khỏi trình duyệt của bạn.
Thay vào đó, bạn đang loại bỏ hỗ trợ CORS khỏi Spring Security, và người dùng sẽ không thể tương tác với backend Spring của bạn từ một ứng dụng trình duyệt cross-origin.
Để khắc phục lỗi CORS trong ứng dụng, bạn phải bật hỗ trợ CORS và cung cấp một nguồn cấu hình phù hợp.
====
