[[oauth2login]]
= Đăng nhập OAuth 2.0
:page-section-summary-toc: 1

Tính năng Đăng nhập OAuth 2.0 cho phép người dùng đăng nhập vào ứng dụng bằng tài khoản hiện có của họ tại một OAuth 2.0 Provider (chẳng hạn như GitHub) hoặc OpenID Connect 1.0 Provider (chẳng hạn như Google).
Đăng nhập OAuth 2.0 triển khai hai trường hợp sử dụng: "`Đăng nhập bằng Google`" hoặc "`Đăng nhập bằng GitHub`".

[NOTE]
====
Đăng nhập OAuth 2.0 được triển khai bằng cách sử dụng *Authorization Code Grant*, như được quy định trong https://tools.ietf.org/html/rfc6749#section-4.1[OAuth 2.0 Authorization Framework] và https://openid.net/specs/openid-connect-core-1_0.html#CodeFlowAuth[OpenID Connect Core 1.0].
====
