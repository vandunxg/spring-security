[[oauth2AuthorizationServer]]
= OAuth 2.1 Authorization Server
:page-section-summary-toc: 1

Các tính năng OAuth 2.1 Authorization Server hỗ trợ vai trò Authorization Server được định nghĩa trong https://datatracker.ietf.org/doc/html/draft-ietf-oauth-v2-1-07#section-1.1[OAuth 2.1 Authorization Framework].

Các tính năng Authorization Server cung cấp implementation của các đặc tả https://datatracker.ietf.org/doc/html/draft-ietf-oauth-v2-1-07[OAuth 2.1], https://openid.net/specs/openid-connect-core-1_0.html[OpenID Connect 1.0] và các đặc tả liên quan khác.
Nó cung cấp nền tảng an toàn, nhẹ và có thể tùy chỉnh để xây dựng Identity Provider OpenID Connect 1.0 và các sản phẩm OAuth 2.1 Authorization Server.

[[oauth2AuthorizationServer-use-cases]]
== Trường hợp sử dụng

Danh sách sau đưa ra một số trường hợp sử dụng Spring Security Authorization Server thay vì sử dụng sản phẩm Provider OAuth2 hoặc OpenID Connect 1.0 mã nguồn mở hay thương mại.

* Cung cấp toàn quyền kiểm soát cấu hình và tùy chỉnh khi cần các kịch bản tùy chỉnh nâng cao.
* Ưu tiên một Authorization Server nhẹ thay vì sản phẩm thương mại bao gồm mọi tính năng nâng cao.
* Có thể tiết kiệm chi phí cấp phép phần mềm và/hoặc chi phí hosting.
* Khởi động nhanh và dễ sử dụng trong quá trình phát triển nhờ mô hình lập trình Spring quen thuộc.
