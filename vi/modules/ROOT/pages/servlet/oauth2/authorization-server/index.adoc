[[oauth2AuthorizationServer]]
= OAuth 2.1 Authorization Server
:page-section-summary-toc: 1

Các tính năng của OAuth 2.1 Authorization Server hỗ trợ vai trò Authorization Server được định nghĩa trong https://datatracker.ietf.org/doc/html/draft-ietf-oauth-v2-1-07#section-1.1[OAuth 2.1 Authorization Framework].

Các tính năng của Authorization Server cung cấp implementation cho các đặc tả https://datatracker.ietf.org/doc/html/draft-ietf-oauth-v2-1-07[OAuth 2.1], https://openid.net/specs/openid-connect-core-1_0.html[OpenID Connect 1.0] và các đặc tả liên quan khác.
Nó cung cấp nền tảng an toàn, gọn nhẹ và có thể tùy chỉnh để xây dựng các Identity Provider của OpenID Connect 1.0 và các sản phẩm OAuth 2.1 Authorization Server.

[[oauth2AuthorizationServer-use-cases]]
== Các use case

Danh sách sau nêu một số use case khi sử dụng Spring Security Authorization Server thay vì sử dụng một sản phẩm Provider cho OAuth2 hoặc OpenID Connect 1.0, dù là mã nguồn mở hay thương mại.

* Toàn quyền kiểm soát cấu hình và tùy chỉnh cho các kịch bản nâng cao.
* Ưu tiên một Authorization Server gọn nhẹ thay vì sản phẩm thương mại có đầy đủ tính năng nâng cao.
* Có thể tiết kiệm chi phí cấp phép phần mềm và/hoặc chi phí hosting.
* Khởi động nhanh và dễ sử dụng trong quá trình phát triển nhờ mô hình lập trình Spring quen thuộc.
