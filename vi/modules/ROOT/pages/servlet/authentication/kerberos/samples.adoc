[[springsecuritykerberossamples]]
= Các mẫu Spring Security Kerberos
:figures: servlet/authentication/kerberos

Phần này của tài liệu tham khảo giới thiệu các dự án mẫu. Có thể biên
dịch các mẫu thủ công bằng cách xây dựng bản phân phối chính từ
https://github.com/spring-projects/spring-security-kerberos.

[IMPORTANT]
====
Nếu chạy mẫu nguyên trạng, mẫu sẽ không hoạt động cho đến khi áp dụng
cấu hình chính xác. Xem các ghi chú bên dưới cho từng mẫu cụ thể.
====

<<samples-sec-server-win-auth>> mẫu cho môi trường Windows

<<samples-sec-server-client-auth>> mẫu sử dụng trình xác thực phía server

<<samples-sec-server-spnego-form-auth>> mẫu sử dụng việc kiểm tra tính hợp lệ của ticket
với spnego và form

<<samples-sec-client-rest-template>> mẫu cho KerberosRestTemplate

[[samples-sec-server-win-auth]]
== Mẫu xác thực Windows của Security Server
Mục tiêu của mẫu này:

- Trong môi trường Windows, người dùng có thể đăng nhập vào ứng dụng
  bằng credential của Windows Active Directory đã được nhập khi đăng nhập
  vào Windows. Người dùng không cần cung cấp credential userid/password.
- Trong môi trường không phải Windows, người dùng sẽ được hiển thị một màn
  hình để cung cấp credential của Active Directory.

[source,yaml,indent=0]
----
server:
    port: 8080
    app:
        ad-domain: EXAMPLE.ORG
        ad-server: ldap://WIN-EKBO0EQ7TS7.example.org/
        service-principal: HTTP/neo.example.org@EXAMPLE.ORG
        keytab-location: /tmp/tomcat.keytab
        ldap-search-base: dc=example,dc=org
        ldap-search-filter: "(| (userPrincipalName={0}) (sAMAccountName={0}))"
----
Ở trên là cấu hình mặc định cho mẫu này. Bạn có thể ghi đè các thiết lập
này bằng các cách thông thường của Spring Boot, chẳng hạn như sử dụng tùy
chọn dòng lệnh hoặc file `application.yml` tùy chỉnh.

Chạy một server.
[source,text,subs="attributes"]
----
$ java -jar sec-server-win-auth-{spring-security-version}.jar
----

[IMPORTANT]
====
Bạn có thể cần sử dụng cấu hình Kerberos tùy chỉnh với Linux bằng một
trong các cách sau:
`-Djava.security.krb5.conf=/path/to/krb5.ini` hoặc
`GlobalSunJaasKerberosConfig` bean.
====

[NOTE]
====
Xem xref:servlet/authentication/kerberos/appendix.adoc#setupwinkerberos[Thiết lập Windows Domain Controller]
để biết thêm hướng dẫn về cách làm việc với môi trường Kerberos trên Windows.
====

[[samples-sec-server-client-auth]]
== Mẫu xác thực phía server của Security Server
Mẫu này minh họa cách server có thể thực hiện authentication cho người dùng
với môi trường Kerberos bằng credential của họ được truyền qua form login.

Chạy một server.
[source,text,subs="attributes"]
----
$ java -jar sec-server-client-auth-{spring-security-version}.jar
----

[source,yaml,indent=0]
----
server:
    port: 8080
----

[[samples-sec-server-spnego-form-auth]]
== Mẫu xác thực Spnego và Form của Security Server
Mẫu này minh họa cách cấu hình server để chấp nhận thương lượng dựa trên
Spnego từ trình duyệt, đồng thời vẫn có thể chuyển về authentication
dựa trên form.

Sử dụng principal `user1`, xref:servlet/authentication/kerberos/appendix.adoc#setupmitkerberos[Thiết lập MIT Kerberos],
thực hiện đăng nhập Kerberos thủ công bằng credential.
[source,text]
----
$ kinit user1
Password for user1@EXAMPLE.ORG:

$ klist
Ticket cache: FILE:/tmp/krb5cc_1000
Default principal: user1@EXAMPLE.ORG

Valid starting     Expires            Service principal
10/03/15 17:18:45  11/03/15 03:18:45  krbtgt/EXAMPLE.ORG@EXAMPLE.ORG
  renew until 11/03/15 17:18:40
----

hoặc sử dụng file keytab.

[source,text]
----
$ kinit -kt user2.keytab user1

$ klist
Ticket cache: FILE:/tmp/krb5cc_1000
Default principal: user2@EXAMPLE.ORG

Valid starting     Expires            Service principal
10/03/15 17:25:03  11/03/15 03:25:03  krbtgt/EXAMPLE.ORG@EXAMPLE.ORG
  renew until 11/03/15 17:25:03
----

Chạy một server.
[source,text,subs="attributes"]
----
$ java -jar sec-server-spnego-form-auth-{spring-security-version}.jar
----

Bây giờ bạn có thể mở trình duyệt và để trình duyệt thực hiện
authentication Spnego bằng ticket hiện có.

[NOTE]
====
Xem xref:servlet/authentication/kerberos/appendix.adoc#browserspnegoconfig[Cấu hình trình duyệt để thương lượng Spnego]
để biết thêm hướng dẫn cấu hình trình duyệt sử dụng Spnego.
====

[source,yaml,indent=0]
----
server:
    port: 8080
app:
    service-principal: HTTP/neo.example.org@EXAMPLE.ORG
    keytab-location: /tmp/tomcat.keytab
----

[[samples-sec-client-rest-template]]
== Mẫu KerberosRestTemplate của Security Client
Đây là mẫu sử dụng Spring RestTemplate để truy cập tài nguyên được bảo vệ
bởi Kerberos. Bạn có thể sử dụng mẫu này cùng với
<<samples-sec-server-spnego-form-auth>>.

Ứng dụng mặc định được cấu hình như bên dưới.
[source,yaml,indent=0]
----
app:
    user-principal: user2@EXAMPLE.ORG
    keytab-location: /tmp/user2.keytab
    access-url: https://neo.example.org:8080/hello
----


Sử dụng principal `user1`, xref:servlet/authentication/kerberos/appendix.adoc#setupmitkerberos[Thiết lập MIT Kerberos],
thực hiện đăng nhập Kerberos thủ công bằng credential.
[source,text,subs="attributes"]
----
$ java -jar sec-client-rest-template-{spring-security-version}.jar --app.user-principal --app.keytab-location
----

[NOTE]
====
Ở trên, chúng ta chỉ cần đặt `app.user-principal` và `app.keytab-location`
thành các giá trị rỗng, qua đó vô hiệu hóa việc sử dụng file keytab.
====

Nếu thao tác thành công, bạn sẽ thấy kết quả bên dưới với `user1@EXAMPLE.ORG`.
[source,text]
----
<html xmlns="https://www.w3.org/1999/xhtml"
      xmlns:sec="https://www.thymeleaf.org/thymeleaf-extras-springsecurity3">
  <head>
    <title>Spring Security Kerberos Example</title>
  </head>
  <body>
    <h1>Hello user1@EXAMPLE.ORG!</h1>
  </body>
</html>
----

Hoặc sử dụng `user2` với file keytab.
[source,text,subs="attributes"]
----
$ java -jar sec-client-rest-template-{spring-security-version}.jar
----

Nếu thao tác thành công, bạn sẽ thấy kết quả bên dưới với `user2@EXAMPLE.ORG`.
[source,text]
----
<html xmlns="https://www.w3.org/1999/xhtml"
      xmlns:sec="https://www.thymeleaf.org/thymeleaf-extras-springsecurity3">
  <head>
    <title>Spring Security Kerberos Example</title>
  </head>
  <body>
    <h1>Hello user2@EXAMPLE.ORG!</h1>
  </body>
</html>
----
