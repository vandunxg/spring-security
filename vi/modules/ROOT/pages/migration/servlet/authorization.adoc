= Các thay đổi về authorization

== Nếu sử dụng Access API, thêm `spring-security-access`

Spring Security 7 chuyển `AccessDecisionManager`, `AccessDecisionVoter` và Access API liên quan sang một module legacy, `spring-security-access`.
Kể từ Spring Security 5, Access API đã bị deprecated để ưu tiên sử dụng Authorization API.

Bạn có thể thêm dependency này như các dependency Spring Security khác:

[tabs]
======
Maven::
+
[source,xml,role="primary"]
----
<dependency>
    <groupId>org.springframework.security</groupId>
    <artifactId>spring-security-access</artifactId>
</dependency>
----

Gradle::
+
[source,groovy,role="primary"]
----
implementation('org.springframework.security:spring-security-access')
----
======
