= Reactive

Nếu bạn đã thực hiện xref:migration/index.adoc[các bước chuyển đổi ban đầu] cho ứng dụng Reactive của mình, giờ bạn đã sẵn sàng thực hiện các bước dành riêng cho ứng dụng Reactive.

== Xác thực Header `typ` bằng `JwtTypeValidator`

Nếu khi thực hiện các bước chuẩn bị cho 6.5 bạn đã đặt `validateTypes` thành `false`, giờ bạn có thể xóa cấu hình này.
Bạn cũng có thể xóa phần thêm tường minh `JwtTypeValidator` vào danh sách mặc định.

Ví dụ, thay đổi từ:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
@Bean
JwtDecoder jwtDecoder() {
	NimbusReactiveJwtDecoder jwtDecoder = NimbusReactiveJwtDecoder.withIssuerLocation(location)
        .validateTypes(false) <1>
        // ... your remaining configuration
        .build();
	jwtDecoder.setJwtValidator(JwtValidators.createDefaultWithValidators(
		new JwtIssuerValidator(location), JwtTypeValidator.jwt())); <2>
	return jwtDecoder;
}
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
@Bean
fun jwtDecoder(): JwtDecoder {
    val jwtDecoder = NimbusReactiveJwtDecoder.withIssuerLocation(location)
        .validateTypes(false) <1>
        // ... your remaining configuration
        .build()
    jwtDecoder.setJwtValidator(JwtValidators.createDefaultWithValidators(
        JwtIssuerValidator(location), JwtTypeValidator.jwt())) <2>
    return jwtDecoder
}
----
======
<1> - Tắt việc Nimbus xác minh `typ`
<2> - Thêm trình xác thực `typ` mặc định

thành:

[tabs]
======
Java::
+
[source,java,role="primary"]
----
@Bean
NimbusReactiveJwtDecoder jwtDecoder() {
	NimbusJwtDecoder jwtDecoder = NimbusReactiveJwtDecoder.withIssuerLocation(location)
        // ... your remaining configuration <1>
        .build();
	jwtDecoder.setJwtValidator(JwtValidators.createDefaultWithIssuer(location)); <2>
	return jwtDecoder;
}
----

Kotlin::
+
[source,kotlin,role="secondary"]
----
@Bean
fun jwtDecoder(): NimbusReactiveJwtDecoder {
    val jwtDecoder = NimbusReactiveJwtDecoder.withIssuerLocation(location)
        // ... your remaining configuration
        .build()
    jwtDecoder.setJwtValidator(JwtValidators.createDefaultWithIssuer(location)) <2>
    return jwtDecoder
}
----
======
<1> - `validateTypes` hiện mặc định là `false`
<2> - `JwtTypeValidator#jwt` được tất cả các phương thức `createDefaultXXX` thêm vào
