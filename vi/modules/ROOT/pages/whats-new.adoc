= Có gì mới trong Spring Security 7.2

== Authentication

* https://github.com/spring-projects/spring-security/issues/17655[gh-17655] - Đặt việc xref:servlet/authentication/onetimetoken.adoc#validating-account-status[kiểm tra trạng thái tài khoản] của One-Time Token thành tùy chọn

== Web

* Vì `HttpMethod#valueOf` của Spring Framework hiện chuẩn hóa cách viết hoa/thường, `StrictServerWebExchangeFirewall` không còn phát hiện một phương thức HTTP có cách viết hoa/thường không chuẩn (ví dụ `get` thay vì `GET`) là một giá trị riêng biệt; các request như vậy được xử lý theo phương thức chuẩn thay vì bị từ chối. Các ứng dụng đã tùy chỉnh `ServerExchangeRejectedHandler` cần lưu ý rằng handler này không còn được gọi trong trường hợp này.
