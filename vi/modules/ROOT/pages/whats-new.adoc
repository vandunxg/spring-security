= Có gì mới trong Spring Security 7.2

== Authentication

* https://github.com/spring-projects/spring-security/issues/17655[gh-17655] - Đặt việc xref:servlet/authentication/onetimetoken.adoc#validating-account-status[kiểm tra trạng thái tài khoản] của One-Time Token ở chế độ opt-in

== Web

* Vì `HttpMethod#valueOf` của Spring Framework hiện chuẩn hóa casing, `StrictServerWebExchangeFirewall` không còn detect một HTTP method có casing không canonical (ví dụ `get` thay vì `GET`) là một value riêng biệt; các request như vậy được process theo canonical method thay vì bị reject. Các application đã customize `ServerExchangeRejectedHandler` cần lưu ý rằng handler này không còn được invoke trong trường hợp này.
