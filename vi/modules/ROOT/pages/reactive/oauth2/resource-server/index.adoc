[[webflux-oauth2-resource-server]]
= OAuth 2.0 Resource Server

Spring Security hỗ trợ bảo vệ các endpoint bằng cách cung cấp hai dạng OAuth 2.0 https://tools.ietf.org/html/rfc6750.html[Bearer Tokens]:

* https://tools.ietf.org/html/rfc7519[JWT]
* Opaque Tokens

Điều này hữu ích trong các trường hợp ứng dụng đã ủy quyền việc quản lý authority của mình cho một https://tools.ietf.org/html/rfc6749[Authorization Server] (ví dụ: Okta hoặc Ping Identity).
Các Resource Server có thể tham vấn Authorization Server này để thực hiện authorization cho các request.

====
