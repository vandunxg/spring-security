[[webflux-oauth2-login]]
= OAuth 2.0 Login
:page-section-summary-toc: 1

Tính năng OAuth 2.0 Login cho phép người dùng đăng nhập vào ứng dụng bằng tài khoản hiện có của họ tại một OAuth 2.0 Provider (chẳng hạn như GitHub) hoặc OpenID Connect 1.0 Provider (chẳng hạn như Google).
OAuth 2.0 Login triển khai hai use case: "`Đăng nhập bằng Google`" hoặc "`Đăng nhập bằng GitHub`".

[NOTE]
====
OAuth 2.0 Login được triển khai bằng *Authorization Code Grant*, theo quy định tại https://tools.ietf.org/html/rfc6749#section-4.1[OAuth 2.0 Authorization Framework] và https://openid.net/specs/openid-connect-core-1_0.html#CodeFlowAuth[OpenID Connect Core 1.0].
====
