[[integrations]]
= Tích hợp
:page-section-summary-toc: 1

Spring Security cung cấp khả năng tích hợp với nhiều framework và API.
Trong phần này, chúng ta thảo luận về các tích hợp chung không dành riêng cho môi trường Servlet hoặc Reactive.
Để xem các tích hợp cụ thể, hãy tham khảo các phần Tích hợp xref:servlet/integrations/index.adoc[Servlet] và Tích hợp xref:reactive/integrations/cors.adoc[Reactive].
