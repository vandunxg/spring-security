[[authorization]]
= Authorization

Spring Security cung cấp hỗ trợ toàn diện cho https://en.wikipedia.org/wiki/Authorization[authorization].
Authorization là việc xác định ai được phép truy cập một tài nguyên cụ thể.
Spring Security cung cấp https://en.wikipedia.org/wiki/Defense_in_depth_(computing)[phòng thủ theo chiều sâu] bằng cách cho phép authorization dựa trên request và authorization dựa trên method.

[[authorization-request]]
== Authorization dựa trên request

Spring Security cung cấp authorization dựa trên request cho cả môi trường xref:servlet/authorization/authorize-http-requests.adoc[Servlet] và xref:reactive/authorization/authorize-http-requests.adoc[WebFlux].

[[authorization-method]]
== Authorization dựa trên method

Spring Security cung cấp authorization dựa trên việc gọi method cho cả môi trường xref:servlet/authorization/method-security.adoc[Servlet] và xref:reactive/authorization/method.adoc[WebFlux].
