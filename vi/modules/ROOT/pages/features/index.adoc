[[features]]
= Tính năng
:page-section-summary-toc: 1

Spring Security cung cấp hỗ trợ toàn diện cho xref:features/authentication/index.adoc[authentication], xref:features/authorization/index.adoc[authorization] và khả năng bảo vệ trước xref:features/exploits/index.adoc#exploits[các hình thức khai thác phổ biến].
Nó cũng cung cấp khả năng tích hợp với các thư viện khác để đơn giản hóa việc sử dụng.
