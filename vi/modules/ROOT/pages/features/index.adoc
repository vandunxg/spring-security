[[features]]
= Tính năng
:page-section-summary-toc: 1

Spring Security cung cấp hỗ trợ toàn diện cho xref:features/authentication/index.adoc[authentication] và xref:features/authorization/index.adoc[authorization], đồng thời bảo vệ trước xref:features/exploits/index.adoc#exploits[các exploit phổ biến].
Nó cũng cung cấp khả năng tích hợp với các thư viện khác để đơn giản hóa việc sử dụng.
