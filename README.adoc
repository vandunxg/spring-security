= Spring Security

Spring Security provides security services for the https://docs.spring.io[Spring IO Platform]. Spring Security 6.0 requires Spring 6.0 as
a minimum and also requires Java 17.

For a detailed list of features and access to the latest release, please visit https://spring.io/projects[Spring projects].

== Building the Documentation Site

This fork is maintained as a documentation-only Spring Security translation project.
English documentation lives under `docs/` and Vietnamese documentation under `vi/`.

* `scripts/sync-spring-security-docs.sh` refreshes the English documentation from the official `spring-projects/spring-security` `main` branch.
* `.upstream-version` records the upstream commit currently mirrored.
* `vi/CLAUDE.md` contains the translation rules and `vi/PROGRESS.md` tracks translation progress.
* `antora-playbook.yml` builds English at the site root and Vietnamese under `/vi/`.

Install the Antora toolchain once and build from the repository root:

[source,shell]
----
$ npm ci --prefix antora
$ ./antora/node_modules/.bin/antora antora-playbook.yml
----

The generated site is written to `build/site`.
Pushing to `main` triggers `.github/workflows/deploy-docs.yml` for GitHub Pages.

To configure the official upstream remote in a local clone:

[source,shell]
----
$ git remote add upstream https://github.com/spring-projects/spring-security.git
$ ./scripts/sync-spring-security-docs.sh
----
